# Dashboard de Atendimentos no Cliente

Este repositório contém o acesso seguro ao dashboard criado no **Data Studio (Looker Studio)**.

## 🔗 Acesso ao Dashboard
[Visualizar Dashboard](https://datastudio.google.com/reporting/9d6e212b-4caf-46ac-ac1e-c613d32e9e97)

## 📊 Descrição
O dashboard apresenta:
- Indicadores de atendimentos ON/OFF e entre outros
- Gráficos de barras filtrados (sem valores em branco)

## 🛠️ Tecnologias Usadas
- Google Sheets → Fonte de dados
- Data Studio (antigo Looker Studio) → Criação do dashboard

## 🚀 Como usar
1. Abra o link acima no navegador (desktop ou celular).
2. Interaja com os gráficos.
